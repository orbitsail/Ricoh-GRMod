# tools/shadowml/train: training pipeline (reference)

The pipeline that produced `../model/model_final.bin` (`pipeline/` the curve and shading fits, `model/` the label analysis, tree fitting and selection, `tools/` the FiveK/DNG preparation). Scripts only: no labels, caches, images or data. Paths are relative to `$GRIV_WORK`, a working directory laid out like the session scratchpad (`shadowml/`, `grdng/`, ...); they are not part of any test suite and were not re-run after the move. See `docs/griv-re/testing.md` section 4.
